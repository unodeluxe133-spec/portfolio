# E-portfolio N7 — Version 3

## Ouvrir le site
1. Décompressez `eportfolio_n7_v3.zip`.
2. Ouvrez le dossier `eportfolio_n7_v3` dans VS Code.
3. Ouvrez `index.html` dans votre navigateur ou utilisez l'extension Live Server.

## Choix de cette version
- Identité visuelle conservée : verts inspirés de la végétation guyanaise, bleus évoquant le spatial, fond clair et typographie sobre.
- Ton plus professionnel et moins autobiographique : le site met l'accent sur la formation, les projets, la mobilité et le projet professionnel.
- Le projet de batterie est présenté sans résultats inventés ; les détails pourront être complétés à partir des documents de référence.
- Les rubriques engagement et activités restent à compléter avec des informations réelles.

## À finaliser
- Vérifier les intitulés officiels des formations et des projets.
- Compléter les projets, les activités, les CV, la vidéo de présentation, les modèles professionnels et les options de mobilité selon les consignes du cours.
- Ajouter des photos seulement si elles apportent une preuve ou une explication utile (montage expérimental, schéma, résultat de projet). L'illustration d'accueil est faite en CSS, sans photo externe.
- Ajouter une adresse de contact si souhaité.
